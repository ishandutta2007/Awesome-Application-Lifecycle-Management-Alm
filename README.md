- **[Spree Commerce](https://github.com/spree/spree)** [![Stars](https://img.shields.io/github/stars/spree/spree?style=social&color=white)](https://github.com/spree/spree/stargazers)  
  **Open Source Platform for DTC, B2B Commerce, Marketplaces & Omnichannel**, BSD 3-Clause licensed. **16K+ GitHub stars, 5K forks** [citation:14] — **the leading open-source marketplace platform with zero platform fees** [citation:9]. **Seller onboarding with configurable checklists, orders split per seller, flexible commission engine, payout ledger with Stripe Connect, and dedicated Seller Panel — all in the open-source core** [citation:9]. **Production-ready Next.js storefront (Next.js 16, React 19, Tailwind CSS 4, TypeScript)** [citation:9]. **REST APIs, TypeScript SDKs (Store, Admin, Seller), React Admin Dashboard with plugin extension** [citation:9]. **Agentic Development skills for Claude Code, Cursor, Copilot, and 60+ AI tools** [citation:9]. **Powers Maisonette's 65,000+ product marketplace from hundreds of brands** [citation:12]. **Enterprise Edition adds Stripe Connect payouts, Adyen for Platforms, multi-tenant SaaS, and cross-border commerce** [citation:12]. 🚀

- **[Mercur](https://github.com/mercurjs/mercur)** [![Stars](https://img.shields.io/github/stars/mercurjs/mercur?style=social&color=white)](https://github.com/mercurjs/mercur/stargazers)  
  **The complete open source platform to run your entire marketplace**, open-source. **The first truly limitless open source marketplace platform** — **combines the simplicity of SaaS with the freedom of open source** [citation:7]. **Built on MedusaJS** — **inherits a mature, battle-tested commerce core (catalog, orders, payments, shipping, tax, stock) instead of reinventing it** [citation:18]. **Vendor onboarding, multi-vendor catalogs, offers, commissions, and automated payouts are built in** [citation:18]. **Multiple sellers can list offers against the same product** [citation:18]. **Headless and customizable without forks** — **TypeScript, event-driven, API-first** [citation:18]. **Admin Panel + Vendor Panel + B2C/B2B Storefronts** [citation:18]. **Stripe Connect payout provider included** [citation:18]. **Run B2C, B2B, and hybrid marketplaces with no percentage of GMV, no per-transaction cut, and no vendor lock-in** [citation:18]. 🎯

  **The world's most flexible commerce platform**, MIT licensed. **The foundation for Mercur and many custom marketplace implementations** [citation:7][citation:18]. **Modular architecture with 22+ commerce modules** [citation:18]. **TypeScript/Node.js + PostgreSQL**. **The most flexible open-source commerce engine for building custom storefronts**. 🛒

## ⚠️ Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement. ℹ️
- **Spree Commerce is the leading open-source marketplace platform** with **16K+ GitHub stars and zero platform fees** [citation:9][citation:14]. **Mercur is the first truly limitless open-source marketplace platform**, built on **MedusaJS with vendor onboarding, commissions, and payouts built into the core** [citation:7][citation:18].
